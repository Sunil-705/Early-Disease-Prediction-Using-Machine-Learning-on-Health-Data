# Dataset and Technical References

1. Janosi, A., Steinbrunn, W., Pfisterer, H., & Detrano, R. (1989). **Heart Disease**. UCI Machine Learning Repository, dataset ID 45. DOI: https://doi.org/10.24432/C52P4X. Dataset page: https://archive.ics.uci.edu/dataset/45/heart+disease. The repository states that the Cleveland target takes values 0–4 and common binary experiments group 1–4 as disease presence vs 0 as absence. Review original documentation before use.
2. **Pima Indians Diabetes Database**. Legacy UCI archive copy. Historical data file: https://archive.ics.uci.edu/ml/machine-learning-databases/pima-indians-diabetes/pima-indians-diabetes.data. If the legacy endpoint is unavailable, the acquisition helper falls back to a public mirror: https://raw.githubusercontent.com/jbrownlee/Datasets/master/pima-indians-diabetes.data.csv. The dataset is commonly described as 768 records from adult female Pima patients; confirm original attribution/licence for redistribution.
3. **UCI Diabetes dataset, current dataset ID 34**: https://archive.ics.uci.edu/dataset/34/diabetes. This is an AIM '94 time-series dataset of glucose/insulin/event records, not the Pima Indians Diabetes table. Do not cite it as Pima.
4. Pedregosa, F. et al. (2011). Scikit-learn: Machine Learning in Python. *Journal of Machine Learning Research*, 12, 2825–2830. https://jmlr.org/papers/v12/pedregosa11a.html.
5. Lundberg, S. M., & Lee, S.-I. (2017). A Unified Approach to Interpreting Model Predictions. *Advances in Neural Information Processing Systems*. https://proceedings.neurips.cc/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html.
6. Streamlit documentation: https://docs.streamlit.io/.
